Deskripsi Repository
Repository ini merupakan dokumentasi resmi dari kegiatan Day 1 Proyek Workshop. Di dalam repository ini tersimpan catatan materi, poin-poin pembelajaran penting, serta refleksi pribadi selama mengikuti rangkaian acara pada hari pertama.

Tujuan Repository
Penyimpanan Dokumentasi: Menjadi wadah pencatatan materi dan pengetahuan yang didapatkan selama sesi workshop.
Pemenuhan Tugas: Memenuhi persyaratan evaluasi dan pengumpulan tugas Day 1 Proyek Workshop.
Portofolio Pembelajaran: Sebagai rekam jejak digital atas proses belajar dan pengembangan keterampilan teknis.
Pemahaman Akademik & Karir: Memahami seluk-beluk TIK, kurikulum, serta profil lulusan sebagai arah studi dan persiapan magang.
Penguasaan Prompt Engineering: Melatih kemampuan prompting AI secara terstruktur untuk mempercepat pembuatan proyek aplikasi dan website.
Portofolio & Dokumentasi GitHub: Membiasakan standar dokumentasi teknis di GitHub sebagai portofolio digital dan syarat evaluasi tugas.
Dokumentasi Kegiatan Workshop (Day 1)

Rangkuman Materi Berikut adalah rangkuman materi yang disampaikan pada sesi workshop hari pertama:
Seluk-Beluk TIK: Pembahasan mengenai visi, misi, dan fondasi utama dari Jurusan Teknik Informatika dan Komputer (TIK). Profil Lulusan Tiap Jurusan/Prodi: Penjelasan mengenai gambaran kompetensi, keahlian, dan prospek karir lulusan di masing-masing program studi TIK. Kurikulum & Program Magang: Penyampaian struktur kurikulum perkuliahan serta alur persiapan program magang industri bagi mahasiswa. Prompt Engineering (GitHub & AI Tools): Pembelajaran teknik prompt engineering baik secara manual maupun memanfaatkan berbagai alat AI populer (seperti ChatGPT, Claude, Gemini, DeepSeek, dan Grok) yang terintegrasi dengan workflow GitHub.

Poin-Poin Penting & Pengetahuan Baru Beberapa wawasan baru dan poin penting yang dipelajari selama sesi:
Penyusunan Prompt Terstruktur: Memahami cara merancang instruksi (prompting) ke AI secara lebih sistematis dan spesifik untuk membantu eksekusi proyek atau tugas teknis (seperti membuat aplikasi dan website). Optimalisasi AI sebagai Workflow Assistant: Mempelajari bagaimana memanfaatkan AI generasi terbaru untuk mempercepat alur pemecahan masalah, penulisan kode, dan pembuatan dokumen teknis.

Pendapat Pribadi tentang Day 1 Proyek Workshop Overall acara TIK mengajar bagus tetapu lumayan membuat saya capek melelahkan terutama di badan bagian punggung dikarenakan tidak ada kursi, tapi insight materi nya bagus walaupun ada kendala dalam sinyal atau internet saat menggunakan nya karena rame, dan sama nasib nya dengan hotspot juga masih jelek signal nya
